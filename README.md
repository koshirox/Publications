# ЛР1. Платформа публикаций
## Файлы
| Файл | Что внутри                                                    |
| --- |---------------------------------------------------------------|
| `database.py` | Подключение к PostgreSQL                                      |
| `models.py` | Пять таблиц: users, categories, posts, comments, subscriptions |
| `crud_users.py` | Работа с пользователями, подписки, персональная лента         |
| `crud_categories.py` | Категории                                                     |
| `crud_posts.py` | Посты и ленты                                                 |
| `crud_comments.py` | Комментарии                                                   |
| `crud_likes.py` | Лайки                                                         |
| `init_db.py` | Создание таблиц                                               |
| `fill_data.py` | Начальные данные (админ, категория "Новости", тестовые юзеры)  |
| `test.py` | Проверка сценариев                                            |
